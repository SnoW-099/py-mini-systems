# py-mini-systems

A collection of small Python projects and practice exercises built for learning logic, file handling, and simple interfaces.

## Projects

### listas
A folder with small list and calculator exercises using Python.

- [listas/main.py](listas/main.py): calculator that performs basic arithmetic operations.
- [listas/mainn.py](listas/mainn.py): program to add, remove, search, and update game names in a list.
- [listas/index.html](listas/index.html): web page placeholder for the project.
- [listas/style.css](listas/style.css): styling file for the HTML page.

### mini-store
Inventory management system for a store — add, search, delete products and apply discounts.

```bash
cd mini-store
python inventario.py
```

### mini-users
User registration and login system with JSON storage.

```bash
cd mini-users
python main.py
```

### Generador_Contrasenas
Password generator project.

```bash
cd Generador_Contrasenas
python main.py
```
